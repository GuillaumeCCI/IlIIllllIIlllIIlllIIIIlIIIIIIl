Les modules

Intégrer les exercices

Deux façons de placer les exercices dans une autre plateforme (LMS, Moodle, site, Notion…) : un module entier, ou un seul thème du module (ses exercices, avec leur navigation). Chaque thème a son code d’intégration, affiché en entier : copiez-le et collez-le dans un bloc HTML de votre LMS.

Mode d’emploi

  1. Lien : à coller tel quel dans un bouton ou une activité « URL ». Les exercices s’ouvrent en plein écran.
  2. Code d’intégration : à coller dans un bloc HTML (« intégrer », « iframe », « code source »). Un thème = une activité du LMS. Le cadre mesure 900 pixels de haut, avec une barre de défilement si l’exercice est plus long.
  3. Hauteur automatique (facultatif) : collez aussi la ligne ci-dessous juste après le code d’intégration, dans le même bloc HTML. C’est la même pour tous les thèmes. Si la plateforme refuse les scripts, le code d’intégration seul fonctionne quand même.
